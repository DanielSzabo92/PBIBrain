The shortest useful reading

Scan once. Keep every kind of truth separate.

Power BI artifacts enter through adapters. The Brain normalizes them, parses DAX, records deterministic facts, proposes meaning with evidence, and stores the result as a canonical graph. The API then compiles only the context a downstream task needs.
